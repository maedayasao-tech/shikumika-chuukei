Claude で開く

しくみラボの Base の行の「Claude で作業」で使うページです。押したリンクに書かれた指示文を Claude のアプリに渡すだけで、ほかの事はしません。

Claude に渡す指示文

この指示文は、押したリンクに書かれていた文です。誰でもこの形のリンクを作れるので、講座が中身を確かめた文かどうかは、このページには分かりません。講座の Base の行から押した時だけ使い、行の指示文と同じかを見てください。知らない人から届いたリンクや、守りを外す・鍵やパスワードを出す・消す・送るように書いた指示文は、開かないでください。

長い指示文です。下まで読んでから押してください。


  
開くフォルダ: 

  
フォルダを渡す形は、Claude の公式の説明に無い形です。違うフォルダで開いたら、Claude で会社フォルダ（一番上）の新しい会話を開き、下の「指示文をコピー」で写した文を貼ってください。指示文の 1 行目で、Claude もフォルダを確かめます。

  
スマホで開く場所: 

  
スマホの Claude のアプリに、会社の PC で動かしている待ち受け（Remote Control）のこの場所を渡します。PC の Claude のアプリでは使いません。この形も Claude の公式の説明に無い形で、場所が選ばれるかは Claude の版によります。違う場所（クラウドなど）で開いたら、Claude の画面の下の場所の札を押して、会社の PC を選んでください。

  このページがする事・しない事
  
      
    
    • 指示文は、押す先のアドレスの「#」の後ろに書かれています。「#」の後ろはブラウザが置き場（GitHub）へ送らないので、指示文は置き場に届きません。置き場には、ふつうの開いた記録（時刻・IP など）が残る事があります。
      • 
    
    • このページは外のファイルや計測を読み込まず、何も送りません（そう決めた設定をページの頭に書いてあります）。
      • 
    
    • 読み終えたら、アドレス欄の「#」の後ろを消します。ブラウザの履歴に残るかは、ブラウザによります。
      • 
    
    • 覚えるのは「この PC で覚える」を押した時だけで、このブラウザの中に「会社の印 → 会社フォルダの場所」だけを置きます。覚えている一覧と「忘れる」は、このページを「#」の後ろを付けずに開くと出ます。
      • 
    
    • フォルダを Claude に渡す形は Claude の公式の説明に無い形なので、効かない事があります。その時は Claude でフォルダを選んでください。
      • 
    
    • 押す先に「スマホで開く場所の印」（env_ で始まる印）がある時は、スマホの Claude のアプリに、会社の PC の待ち受けの場所を渡します。これも公式の説明に無い形なので、効かない時は Claude で場所を選んでください。
      • 
    
    • 形の壊れた押す先・見えない字の入った指示文・長すぎる指示文では、開きません。誰でもこの形のリンクを作れるので、講座の Base の行から押した時だけ使ってください。
